The goal of Who Eats Whom is to create a searchable database of feeding observations on iNaturalist. I was tasked with Enhanced an interactive node-link diagram for food-web exploration using a modern JavaScript visualization library, improving usability and visual clarity.

Skills:
HTML/CSS, Javascript, D3.js, Data Visualization

Implemented an ego-graph focus mode to isolate a selected node and its direct relationships, simplifies complex node relationships, enables focused exploration of food-web structures.

Implemented conditional label rendering to display node information dynamically and reduce visual clutter in complex food-web networks.

Partnered with design team to standardize edge styles and refine arrowhead-to-node connections, improving readability and clarifying directional relationships.
